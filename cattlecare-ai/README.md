# CattleCare AI — 스마트 우사 통합관리 데모

GitHub Pages에 게시할 수 있는 정적 웹사이트입니다. `index.html`, `styles.css`, `app.js` 세 파일을 같은 위치에 보관하면 됩니다.

## 실행

`index.html` 파일을 브라우저로 열면 됩니다. 서버, API 키, 별도 패키지 설치가 필요하지 않습니다.

## GitHub Pages 배포

1. GitHub에 새 Public 저장소를 생성합니다(예: `cattlecare-ai`).
2. 저장소 루트에 `index.html`, `styles.css`, `app.js`를 업로드해 커밋합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch 를 선택합니다.
4. Branch `main`, 폴더 `/(root)`를 선택하고 Save를 누릅니다.
5. 배포 후 GitHub Pages URL(일반적으로 `https://<사용자명>.github.io/cattlecare-ai/`)에서 방문할 수 있습니다. 실제 URL은 GitHub Pages 설정 화면을 확인하세요.

## 구현된 기능

- 12개 상위 메뉴 탐색 및 메뉴별 기록 조회/추가/수정/삭제
- 중앙 자연어 검색창의 키워드 기반 메뉴 자동 이동 및 개체 선택
- 환경 디지털트윈 2D 상태판, 온습도/THI, 팬 상태 불일치 표시
- 체중 ADG, 반추시간 변화, 메탄/DMI 지표, 기간별 SVG 그래프
- 관리자 승인/보류를 통한 작업 상태 기록(실제 장비 제어 없음)
- 날짜 범위, CSV 다운로드, 브라우저 PDF 인쇄, localStorage 저장
- 가상의 소 20두에 대한 시연 기록

## 제한사항

- 검색은 실제 LLM 대신 키워드 기반입니다. 임의의 복잡한 자연어 명령을 모두 이해하지는 않습니다.
- 표시된 모든 초기 데이터는 **가상 시연 데이터**이며 센서/목걸이의 실시간 측정값이 아닙니다.
- 디지털트윈은 구역 상태를 보여주는 초기 2D 시각화이며 검증된 물리 시뮬레이션 모델이 아닙니다.
- 데이터는 접속한 각 브라우저의 localStorage에만 보관됩니다. 공유 계정/DB 서버가 없어 여러 사용자가 같은 데이터를 공유하지 못합니다.
- 로그인/접근통제 기능이 없으므로 실제 농장 개인정보 또는 민감한 데이터를 입력하지 마세요.
- 팬 등의 물리 제어 명령은 전달되지 않습니다. 승인/보류는 화면 안에만 기록됩니다.

## 수업 PPT 적용

지능형축산시설 수업자료의 관측/예측/권고 구분, 원자료 결측 보존, 공급량과 섭취량 구분, 명령과 실제 작동 구분 등의 원칙을 참고했습니다. 원본 양돈장 데이터는 우사 실측값으로 전용하지 않았습니다.
